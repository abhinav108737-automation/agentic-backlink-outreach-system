# CCR-001 — Typed campaign / prospect / approvals / system routes

Status: **APPROVED by the Lead**, executed at integration checkpoint I1.
Filed: 2026-10-16 · Affects contracts **C8** (HTTP API v0) and **C9** (generated TS client).
Contract version: `0.1.0` → `0.2.0`.

## What

Give the campaign, prospect, approvals, settings and system routes real request bodies,
response models and status codes, replacing the untyped `501` stubs frozen at the Foundation
Gate. Regenerate `contracts/openapi/openapi.json` and `contracts/generated_ts/src/api.d.ts`
from the implemented app.

## Why

Integration checkpoint I1 requires the discover → qualify → research → contact slice to be
**exposed through the API** and reachable from the UI. At the freeze every route except
`/health/*` was a `501` stub with no response model, so the committed OpenAPI snapshot and the
generated TS client type nothing beyond health. The slice cannot be exposed without changing
those two generated artefacts, and both are frozen and Lead-only.

This was anticipated rather than discovered: `docs/phase-reports/foundation.md` deviation 7
records that "route stubs return 501 with untyped bodies … Lanes tighten response models via
contract change requests."

## Scope boundary (what this CCR does *not* change)

- `contracts/python/src/kb_contracts/**` is **not** edited, apart from the `CONTRACT_VERSION`
  constant. Response models reuse the already-frozen C2 domain DTOs.
- API **request** bodies live in `apps/api/src/kb_api/schemas/`, inside Lane B's own tree, so no
  new types enter the frozen contract package.
- No enum, state machine, policy, tool-allowlist, provider protocol or event envelope changes.
- `apps/api/src/kb_api/routes/__init__.py` (the frozen router registry) is not edited; every
  route module was pre-registered at the freeze precisely so this would not be necessary.

## Considered and found *not* to require a CCR

| Candidate | Why no change was needed |
|---|---|
| DEFERRED qualification outcome | `QualificationOutcome.DEFERRED` and `BlockCode.METRIC_MISSING` already exist in frozen C1/C6. |
| PostgresJobQueue needing `claim_due` / `complete` / lease reclaim | C5 `JobQueue` is the consumer-facing surface (`enqueue`, `cancel`); a concrete implementation may expose more. The protocol is unchanged. |
| Repository / unit-of-work seam | `kb_core` is not a frozen contract. `kb_core/db/protocols.py` is Lead-owned and frozen for Wave 1 only, to keep Lanes B and C parallel. |
| Mock providers, fixture corpus | Implement frozen C5 protocols and the frozen C12 fixture formats as written. |

## Breaking?

Not in practice. The `501` handlers had no schema and no consumer: the desktop renderer only
calls `/health/*` today. Additive typing of previously untyped endpoints, so the version moves
`0.1.0 → 0.2.0` rather than `1.0.0`. No ADR note is required (docs/14 step 3 applies to
breaking changes).
