# Acceptance Criteria

Product: local campaign runs end-to-end; workflow visible; weekly report generated; decisions explainable.
Discovery: provider abstraction, dedupe, provenance, failure handling.
Qualification: configurable thresholds; hard blocks deterministic; ranking explainable; missing metrics fail safely.
Agentic: Operator delegates; outputs typed; tool scope enforced; runs persisted; Ollama/local path works.
Outreach: mock default; no duplicate sends; limits/suppression/opt-out enforced; replies cancel invalid follow-ups; real send explicit.
Verification: link presence/status and repeated durability checks.
Reporting: reproducible weekly snapshot; numbers deterministic; ROI estimate labels.
Learning: outcome collection; proposal generation; offline test; versioned promotion; rollback.
Engineering: tests/lint/types/migrations pass; no secrets; no mandatory paid API; setup complete; installer works on target OS.
